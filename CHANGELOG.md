# Changelog

## 2.1.0

- Expanded the structure piece pool significantly.
- Added a clutter system: small decorative pieces that appear on walls in corridors and rooms.
- Cisterns/Waterways will sometimes spawn in villages.
- Added a deepslate village variant.
- Loot tables have been rebalanced and expanded with more useful items.
- Fixed structures being allowed to generate above ground.
- Performance improvements to structure generation.
